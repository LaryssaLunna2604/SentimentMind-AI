# SentimentMind AI

Projeto de Inteligência Artificial para análise de sentimento em textos,
classificando mensagens como positivas ou negativas.

## Tecnologias
- Python
- scikit-learn
- NLP (Processamento de Linguagem Natural)

## Funcionalidades
- Treinamento de modelo de IA
- Classificação de sentimentos em texto digitado pelo usuário

## Objetivo
Aplicar conceitos básicos de NLP e Machine Learning em Python.
